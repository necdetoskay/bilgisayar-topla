# AI Agent Tasarimi

## AI'nin Rolu

AI agent bu projede tum kararlari tek basina veren bir kara kutu olmayacaktir. Temel parca uyumlulugu, butce kontrolu ve skor hesabi kuralli motor tarafindan yapilacaktir. AI su alanlarda kullanilacaktir:

- Kullanici istegini teknik onceliklere cevirme
- Profil bazli strateji belirleme
- Onerilen sistemi sade dille aciklama
- Alternatiflerin farkini yorumlama
- Hata raporlarini ozetleme
- Gerekirse scraper bozulmasinda yeni selector adaylarini onermek

## Kullanici Profilleri

| Profil | Oncelik |
|---|---|
| Oyun | GPU agirligi, FPS, dengeli CPU |
| Yazilim | CPU, RAM, SSD, coklu gorev |
| Ofis | Stabilite, dusuk maliyet, sessizlik |
| Grafik | GPU, RAM, renk/ekran disi performans notlari |
| Video | CPU/GPU dengesi, RAM, depolama |
| Ogrenci | Butce, uzun omur, temel performans |

## Skor Boyutlari

- Butce uyumu
- Performans
- Parca dengesi
- Yukseltilebilirlik
- Guc tuketimi
- Marka/tercih uyumu
- Stok ve bulunabilirlik
- Fiyat/performans

## Cikti Formati

Her sistem onerisi su bilgileri icermelidir:

- Parca listesi
- Toplam fiyat
- Kullanim amacina uygunluk puani
- Guclu yanlar
- Zayif yanlar
- Neden bu sistem secildi?
- Daha iyi alternatif icin tahmini ek butce
